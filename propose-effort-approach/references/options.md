# Options

The answer is this block alone, as plain text with no code fence around it (the fence below only marks the template):

```
question: <logbook path> <node>: <the question>
- [<status>] <slug>: <lead line> (<approach file path>)
uncovered: <criterion>, ...
decision: <the brief's first line>
```

One line per option on the question, its status as the effort's section now reads. Leave out `uncovered:` when the options cover every criterion, and `decision:` when no decider ran. Nothing before or after the block: the reasons and what you found are in the logbook.
