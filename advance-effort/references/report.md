# Report

The answer is this block alone, as plain text with no code fence around it (the fence below only marks the template):

```
advanced: <slug>[, via <descendant slug>]
did: <what the run did, one line>
criteria: <criterion> met|unmet|unknown|<metric value>, ...
ask: <the question, standing on its own>
stopped: <why the run stopped>
logbook: <path> <node of the run's goal>
```

One `ask:` line per question the run stopped on or its next action depends on, none when there are none. A guess nothing depended on stays out. `criteria:` lists the effort the run worked on. Nothing before or after the block, no notes on files or commits: whoever started the run reads the logbook for the rest.
