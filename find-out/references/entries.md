# Entries

One entry per question, as plain text with no code fence around it (the fences below only mark the templates):

```
<question>  [what is|what is wanted]
answered: <answer>. From <rung>: <where exactly>.
```

```
<question>  [what is|what is wanted]
unconfirmed: <best answer>. From <rung>: <where exactly>. Settled only by <rung>.
```

```
<question>  [what is|what is wanted]
ask <a person|a stronger model>: <the question, standing on its own>
  found: <what a lower rung gave>, from <rung>: <where exactly>
```

Each entry takes one verdict, `answered`, `unconfirmed` or `ask`, never two: an `ask` already carries what the lower rungs gave on its `found:` lines, so the best answer so far goes there. Only the split from step 1 makes two entries of one question. A `found:` line per lower rung that gave something, none when nothing did. Stop after the last entry, with no preamble or advice. Another skill may read the output as it is, so keep this shape even when talking to a person.
